# Flat-alias paths that do NOT exist on the live GitBook site.
#
# `build_redirects.py --refresh-csv` generates a flat alias for every nested
# page it finds in legacy_sitemap.xml, because GitBook serves some — but not
# necessarily all — nested pages at a flattened path as well. Those rows are
# marked `alias-generated` in redirects.csv: inferred from the pattern, never
# requested against the live site, because this environment cannot reach it.
#
# Each alias produces TWO rows, one per slash form: `/docs/x` and `/docs/x/`.
# The probe settles them separately, because it is the slashless form GitBook
# actually serves and the slashed form is a second inference on top of it.
#
#   confirmed 200 -> edit that row in redirects.csv, changing its source from
#                    `alias-generated` to `alias`. Refresh preserves it and
#                    stops regenerating over it. Its slash sibling stays
#                    `alias-generated` unless the probe confirmed it too —
#                    promote both rows only if both were requested.
#   confirmed 404 -> delete BOTH rows from redirects.csv and add the slashless
#                    path here. One entry here covers both slash forms, so a
#                    row you delete without adding an entry comes straight back
#                    on the next refresh.
#
# One path per line. Blank lines and `#` comments are ignored.
#
# Nothing is excluded yet — the probe has not run.
