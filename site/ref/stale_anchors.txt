# Anchors that were already broken in the GitBook source, page by page.
#
# Each line excuses ONE link on ONE page from `starlight-links-validator`.
# These links point at headings that were renamed upstream, before this
# migration existed, and were never updated — they are broken on the live
# GitBook site today.
#
# Phase 7 repaired 22 of the original 24, two ways:
#
#   - where the section was renamed but stayed on the page, its old id was put
#     back on the heading that replaced it, as `<a id="…"></a>`. That is the
#     only repair that also fixes the indexed anchor URL, which no redirect
#     can reach.
#   - where the section moved to another page, the link was repointed.
#
# The two below are the ones the corpus does not answer. Repairing either
# means writing a section that does not exist, which is a content decision:
#
#   - `#option-3-combining-git-and-shared-drives`: the page has no Option 3
#     any more, and nothing on it describes combining git with a shared drive.
#     The link text is "mix".
#   - `#set-up-a-data-guide`: the Data Guide is mentioned twice in prose and
#     has no section of its own.
#
# This list cannot rot quietly. `staleAnchorsStillStale()` in
# `scripts/build_integrations.mjs` re-derives, on every build, whether each
# line still describes reality, and fails the build naming the line if not:
#
#   - the page no longer exists, or no longer contains that link
#     -> the link was fixed or removed. Delete the line.
#   - the target page no longer exists
#     -> the exclusion is now hiding a genuinely broken link, not a stale
#        anchor. Delete the line and let the validator report it.
#   - the target page now has an element with that id
#     -> the heading was added or renamed back. Delete the line.
#
# So the only way to keep a green build is to delete each line as its anchor
# is repaired. An entry is never a licence for a *new* broken anchor: a link
# not listed here still fails the build, on any page.
#
# Format: <page under src/content/docs/> <link exactly as authored>.
# Blank lines and `#` comments are ignored.
