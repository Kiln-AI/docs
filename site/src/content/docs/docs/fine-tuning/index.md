**Before Fine-Tuning, consider using Kiln's** [**Automatic Prompt Optimizer**](/docs/prompts/automatic-prompt-optimizer/)**.** It has many of the benefits of fine-tuning (automated data driven optimization), while the result is much easier to deploy than a fine-tuned model.
